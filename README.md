## ⚡ Características Principales

- 🔍 **Buscador en Tiempo Real:** Comprueba disponibilidad instantánea consultando la base de datos oficial de `is-a-dev`.
- 📡 **Monitor DNS en Vivo:** Inspecciona la propagación de tus subdominios mediante Google Public DNS over HTTPS.
- 📦 **Vincular Repositorios en 1 Clic:** Conecta tus proyectos de GitHub (`@FrankUsqAbant`) y autorellena el subdominio CNAME para GitHub Pages.
- ⚙️ **DNS Studio & Terminal:** Asistente para registros `CNAME`, `A`, `URL (301)` y `TXT` con copia de JSON y enlace de Pull Request oficial.
