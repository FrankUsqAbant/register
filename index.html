🚀 Flujo de Aprobación de Subdominios

PASO 01
Elegir Repositorio y Dominio
Elige el repositorio que deseas vincular y el subdominio libre que prefieras.
PASO 02

PASO 03
Validación CI Bot
El bot de GitHub Actions de is-a-dev valida la sintaxis y aprueba tu solicitud.
PASO 04
Propagación DNS
En pocos minutos Cloudflare propaga tu subdominio activo en todo el mundo.
